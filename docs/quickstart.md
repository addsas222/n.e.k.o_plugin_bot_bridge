# 机器人插件兼容桥 · 快速上手

把 MaiBot / NoneBot2 / AstrBot / HoshinoBot / discord.py cogs / Koishi 的插件接进 N.E.K.O.。

## 1. 放插件

插件根目录（默认 `<插件数据目录>/data/plugins/`，面板上会显示实际路径）：

```
<插件根目录>/
├── maibot/<插件目录>/          # 目录里要有 _manifest.json + plugin.py
├── nonebot/<插件目录或 .py>    # 目录里要有 __init__.py，或直接放单个 .py
└── astrbot/<插件目录>/         # 目录里要有 metadata.yaml + main.py
```

扁平放（`<插件根目录>/<插件目录>/`）也认。放好后点面板上的「重新扫描插件」。

## 2. 用插件

* **对话**：插件命令已被投影成对话期工具，猫娘会自己调用；也可以让猫娘用
  `bridge_run_command`（可带 `plugin` 点名）把一句话交给某个插件。
* **插件管理器**：每个命令都有对应入口 `bot_cmd_<框架>_<插件>_<命令>`，可手动触发。
* **跨插件**：别的 N.E.K.O. 插件可以调本桥的 `bridge_call_api` / `bridge_run_command`。

## 3. 市场

面板「市场」页：看源状态 → 搜索 → 选中一行 → 安装（会写入插件目录并热重载）。

* 搜索只读；安装是显式动作（不给模型自动调用）。
* 只认官方索引里的条目；落盘布局会按框架校验，装完能立刻被扫到。
* 安装结果会带 `requires`（该插件声明的额外依赖）。生态插件常自带依赖，
  如果 N.E.K.O. 运行时里没有，插件会被跳过并在「插件」页的 errors 里写明缺什么。

## 4. 界面

插件管理器里的「机器人插件兼容桥」面板有四个页签：插件 / 兼容层 / 市场 / 推送。

* 「重新扫描插件」= 重新读插件根目录；「探活 maibot/nonebot/astrbot」= 逐个源主动拉索引
  （一次一个：宿主的单次入口调用默认 30 秒预算，三个源一起拉会被掐断）。
* 市场页：搜索 → 选中一行 → 安装（确认后写入并热重载）。
* 面板按钮报 403「not exposed by surface」= 宿主还没重新加载本插件：先在插件管理器里
  重载它（或重启 N.E.K.O.），再点一次。

## 5. 排障

| 现象 | 看哪里 |
| --- | --- |
| 插件没出现 | 「兼容层」页的 backend errors（缺运行时依赖会写在这里）；「插件」页的 errors（加载失败原因） |
| 命令不响应 | 确认插件在列表里且 running；换 `plugin` 点名调用；检查消息是否符合插件自己的触发规则（NoneBot 命令通常要 `/` 前缀） |
| 消息没进对话 | 「推送」页看最近推送；再看日志 `logs/plugin/N.E.K.O_Plugin_bot_bridge_*.log` 里的 `send_chat … submitted=True` |
| 想临时关掉某个插件 | 面板「插件」页选中它 → **停止**（文件还在，配置里记进 `disabled_plugins`，重启不会拉起）；要恢复就点 **启动** |
| 想彻底删掉某个插件 | 面板「插件」页选中它 → **删除插件**（宿主会先要确认）；插件文件真实删除，数据目录默认保留（要一起清就调 `bridge_delete_plugin` 时传 `purge_state=true`）|
| 市场拉不到 | 「市场」页点**逐源**探活按钮（一次一个源：三源一起拉会超过宿主 iframe 的 30s 单请求上限）；被墙时改 `[bridge.market].mirror_prefixes` |
| 搜索结果只出现一个源的插件 | 已按源轮流取；看结果上方的「各源命中」判断是「某源没命中」还是「某源不可用」 |
| 改了入口/清单要让宿主重读 | `POST /plugin/bot_bridge/reload`（单插件，真机 ~4s；全局 `/plugins/reload` 要 86s） |
